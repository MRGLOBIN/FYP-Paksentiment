Executive Summary
PakSentiment is an AI-powered multilingual sentiment analysis platform developed to analyze public opinion from Pakistani social media and digital platforms. The system focuses on collecting, processing, translating, and analyzing textual data from sources such as Twitter, Reddit, online forums, and web platforms. The main objective of the project is to help policymakers, researchers, NGOs, analysts, and businesses understand public sentiment related to social, political, and economic issues in Pakistan.
Traditional methods of public opinion analysis, such as surveys and manual monitoring, are often time-consuming, costly, and limited in scale. Existing international sentiment analysis platforms mainly focus on English language content and provide limited support for regional Pakistani languages such as Urdu, Punjabi, Pashto, and Roman Urdu. PakSentiment addresses this gap by providing localized multilingual sentiment analysis specifically designed for the Pakistani environment.
The system uses modern Artificial Intelligence (AI), Natural Language Processing (NLP), and Machine Learning (ML) techniques to classify social media posts into positive, negative, and neutral sentiments. The project includes several modules such as data collection, data filtration, translation, sentiment analysis, model evaluation, visualization, and service management. Data is collected automatically through APIs and web scraping tools, then cleaned and preprocessed before analysis. Translation models are used to standardize multilingual content into a consistent format for accurate sentiment classification.
PakSentiment follows a modular and scalable architecture using technologies such as Next.js, NestJS, FastAPI, Go, MongoDB, PostgreSQL, Redis, Docker, and LLaMA-based AI models. The system provides interactive dashboards and visualization tools that display sentiment trends, public reactions, and analytical summaries in real time. Users can also generate reports in formats such as PDF and CSV for research and decision-making purposes.
The project contributes significantly to the fields of Software Engineering, Artificial Intelligence, Data Mining, and Web Development by integrating concepts learned during the BS Software Engineering program. PakSentiment aims to transform large volumes of unstructured social media data into meaningful insights that can support governance, research, public policy evaluation, business intelligence, and social trend monitoring in Pakistan.

Introduction
This chapter provides an overview of the PakSentiment project. It introduces the vision of the system, analyzes existing related systems, and identifies the project deliverables and limitations. The purpose of this chapter is to present the motivation behind the development of the system and outline its intended capabilities and constraints.
Vision Statement
For policymakers, researchers, NGOs, and analysts in Pakistan who need reliable insights into public opinion across multiple languages and online platform. The PakSentiment System Is an AI-powered multilingual sentiment analysis platform that collects public data from social media and digital sources, analyzes sentiment using advanced NLP and machine learning models, and provides interactive dashboards and reports for better decision-making. Unlike traditional survey methods and manual monitoring processes that are slow, fragmented, and limited in scale. Our product provides real-time multilingual sentiment intelligence, automated analysis, and visual insights that help stakeholders understand public opinion efficiently and respond quickly to emerging social trends.
Related System Analysis/Literature Review
 Brandwatch
Brandwatch is a social media monitoring and analytics platform that analyzes public opinion and brand sentiment across various online platforms. It uses artificial intelligence to detect trends and insights from large volumes of online data. However, it primarily focuses on global markets and English language analysis. Its limited support for regional languages makes it less effective for analyzing multilingual discourse in Pakistan.
 Hootsuite Insights
Hootsuite Insights is a social media analytics tool that tracks online conversations and sentiment across different platforms. It helps organizations understand public perception and monitor brand reputation in real time. However, the platform is mainly designed for marketing and brand monitoring rather than governance or public policy analysis. It also lacks specialized support for South Asian languages.
 Google Cloud Natural Language API
Google Cloud Natural Language API provides powerful sentiment analysis and entity recognition features through machine learning models. It is widely used for analyzing textual data and extracting insights. However, the system is not specifically designed for large-scale public sentiment monitoring in a multilingual context. Additionally, reliance on external cloud APIs can create cost and privacy concerns.
IBM Watson Natural Language Understanding
IBM Watson NLU provides advanced text analysis capabilities including sentiment detection, emotion analysis, and entity extraction. It is used by businesses for customer feedback analysis and content understanding. Despite its powerful capabilities, the platform requires extensive configuration and subscription costs, making it less accessible for academic or research projects.

Problem Definition


This chapter describes the main problem that the developed system aims to solve. It explains the current issues in analyzing public opinion from Pakistani social media platforms and highlights how the proposed system will address these problems. The chapter also presents the solution, objectives, scope, and modules of the proposed system.
Problem Statement
In recent years, social media platforms such as Twitter, Facebook, and online forums have become major sources of public opinion in Pakistan. Millions of users express their views about politics, social issues, government policies, brands, and public events through online posts and comments. However, analyzing this massive amount of data manually is extremely difficult and time-consuming. Organizations, researchers, and policymakers often struggle to understand the public sentiment related to different national issues. Currently, there is no centralized system specifically designed to analyze Pakistani social media sentiments in a structured and automated way. Most available tools are either global solutions or do not properly support local languages such as Urdu and Roman Urdu. As a result, a large portion of Pakistani online opinion remains unstructured and underutilized. Businesses and government institutions cannot effectively measure public reactions to their decisions or products. Researchers also face challenges in collecting, filtering, and analyzing large datasets from social media platforms. Furthermore, the lack of proper visualization tools makes it difficult to interpret sentiment trends over time. Without automated analysis, identifying positive, negative, or neutral opinions becomes inefficient. This problem highlights the need for a specialized sentiment analysis system tailored to Pakistani social media content. Therefore, the development of the PakSentiment system aims to collect, process, analyze, and visualize public sentiment from Pakistani social media data in an efficient and automated manner.
Problem Solution
The proposed system, (PakSentiment) is designed to automatically collect and analyze public opinions from social media platforms related to Pakistani topics and issues. The system will gather textual data from online sources using automated data collection techniques. After collecting the data, the system will filter irrelevant or noisy information to ensure accurate analysis. Since many social media posts are written in Urdu or Roman Urdu, the system will include translation and preprocessing mechanisms to standardize the text. Machine learning and natural language processing techniques will then be applied to classify the sentiment of each post as positive, negative, or neutral. The system will also evaluate the performance of the sentiment analysis model to ensure reliability and accuracy. Model improvement techniques will be applied to enhance prediction performance over time. The analyzed data will be presented through visual dashboards that allow users to easily understand public sentiment trends. These visualizations will include graphs, charts, and summaries of public opinion. The system will help researchers, organizations, and policymakers understand public perception regarding different issues. Businesses will be able to analyze customer opinions about products or services. Government institutions can evaluate public responses to policies or announcements. The system will reduce manual effort in data analysis and increase the efficiency of sentiment monitoring. Overall, PakSentiment will provide a centralized platform for analyzing Pakistani social media sentiment using automated and intelligent techniques.
Objectives of the Proposed System
BO-1: Develop an automated system to collect social media data related to Pakistani public opinion.
BO-2: Classify social media posts into positive, negative, and neutral sentiments using machine learning techniques.
BO-3: Improve the accuracy of sentiment analysis models through evaluation and model improvement techniques.
BO-4: Provide graphical visualizations and dashboards to display sentiment trends.
BO-5: Reduce manual effort required to analyze large amounts of social media data.
BO-6: Provide insights that help researchers, organizations, and policymakers understand public opinion.
Scope
The PakSentiment system focuses on analyzing sentiments from Pakistani social media data to understand public opinion trends. The system will collect textual data from social media platforms and store it in a structured database. After data collection, the system will perform filtration to remove irrelevant or duplicate data. The filtered data will then undergo preprocessing and translation processes to handle multiple languages including Urdu and Roman Urdu. The system will apply machine learning algorithms to classify sentiments of social media posts into positive, negative, or neutral categories. Model evaluation techniques will be used to measure the performance of the sentiment classification models. If necessary, the system will apply model improvement methods to enhance prediction accuracy. The processed data and sentiment results will be presented through an interactive visualization dashboard. Users will be able to view sentiment statistics, trends, and graphical summaries. The system will mainly be used for research, analytical, and monitoring purposes. It will allow users to observe how public opinion changes over time regarding specific topics or events. The project focuses on sentiment analysis of textual data rather than multimedia content such as images or videos. The system will operate as a web-based platform accessible to authorized users. PakSentiment will help transform large amounts of unstructured social media data into meaningful insights for decision-making.
Modules
The PakSentiment system consists of several modules responsible for performing different tasks in the sentiment analysis pipeline.
Module 1: Data Collection
FE-1: Collect textual data from social media platforms.FE-2: Store collected data in the system database.FE-3: Schedule automated data collection tasks.




Module 2: Data Filtration
FE-1: Remove duplicate posts and irrelevant data.FE-2: Filter spam or non-informative content.FE-3: Prepare clean data for further processing.




Module 3: Translation
FE-1: Translate Urdu or Roman Urdu text into standardized language format.FE-2: Normalize textual content for analysis.FE-3: Prepare translated text for sentiment analysis.




Module 4: Sentiment Analysis
FE-1: Apply machine learning models for sentiment classification.FE-2: Categorize text into positive, negative, or neutral sentiments.FE-3: Store analysis results in the database.




Module 5: Model Evaluation
FE-1: Measure model accuracy and performance.FE-2: Generate evaluation metrics such as precision, recall, and F1-score.


Module 6: Model Improvement
FE-1: Improve model performance through retraining techniques.FE-2: Optimize parameters for better sentiment classification results.


Module 7: Visualization
FE-1: Display sentiment trends using charts and graphs.FE-2: Provide dashboards for analyzing sentiment distribution.FE-3: Allow users to view summarized analytical reports.




Module 8: Service Manager
FE-1: Manage system services and processes.FE-2: Monitor system performance and task execution.FE-3: Control data processing workflows.

The Use Case technique is used to identify and analyze the functional requirements of the PakSentiment system. Use cases help describe how different users interact with the system to accomplish specific tasks.

Design and Architecture
This chapter describes the overall system architecture and design of the PakSentiment system. It explains how the system is divided into modules and how these modules interact with each other to achieve the required functionality. The chapter also presents the design models used in system development, the data design of the system, and the human interface design that describes how users interact with the system.
Architectural Design
This architecture represents a high-performance, modular sentiment analysis pipeline:
Presentation Layer (Next.js/React): The user-facing dashboard where requests are initiated and results are visualized. It communicates exclusively with the main backend via REST APIs.
Application Layer (Nest.js): Acts as the "Brain" or API Gateway. It manages user authentication, business logic, and orchestrates the other two specialized backend services.
Sidecar Scraper Layer (Go): A high-speed, parallelized service designed for real-time news and web scraping. It uses Go’s concurrency and the Colly framework for maximum throughput, caching raw results in Redis to avoid redundant network calls.
Ingestion & Processing Layer (FastAPI): Specialized for Social Media (Nitter/Twitter/Reddit) and heavy data transformation. This layer handles the preprocessing, Urdu/English translation pipelines, and secondary sentiment classification.
Data Layer (MongoDB/Postgres): The persistent storage where both the Go and Python services write their analyzed results ("ScrapedDocuments") so that the Nest.js server can aggregate them into reports for the user.

Design Models
The system uses a combination of two methodologies, based on the function of each subsystem:
Object-Oriented Programming (OOP): Used in the system's core, including the Nest.js Backend, FastAPI Ingestion Server, and Data Scraping Modules.
Justification: Supports modularity, reusability, and scalability.
Applicable Models: Class Diagram, System Sequence Diagrams (SSD), and Activity Diagrams.
Procedural Programming : Used primarily for the Frontend (React components) where UI rendering is functional and event-driven.
Justification: Aligns with React's functional approach for cleaner component logic, predictable behavior, and easier state management.
Applicable Models: Data Flow Diagram and Activity Diagram 
Process Model
The project follows the Incremental Process Model.
Description: The system is developed in functional segments (increments), where each segment adds new capabilities.
Justification: This model is ideal because the project consists of multiple independent modules (scraping, sentiment model, dashboard) with varying dependencies. It allows for early delivery of working subsystems and supports incremental testing and validation at every stage, reducing overall project risk.

Algorithm 1 Text Preprocessing
Input: Raw text raw_text
Output: Cleaned text clean_text, detected language language_code
1:   clean_text ← raw_text.lower()
2:   Remove URLs, mentions, hashtags from clean_text
3:   Remove emojis, special symbols, and HTML tags
4:   Replace multiple spaces with single space
5:   language_code ← detectLanguage(clean_text)
6:   if length(clean_text) < MIN_LENGTH then
7:        return (NULL, language_code)
8:   end if
9:   return (clean_text, language_code)
Algorithm 2 Translate to Urdu
Input: clean_text, language_code
Output: Boolean value
1:   if language_code == "ur" then
2:        return clean_text
3:   end if
4:   prompt ← "Translate the following text into Urdu:\n" + clean_text
5:   model ← loadLLM("llama-3.2")
6:   response ← model.generate(prompt)
7:   translated_text ← extractText(response)
8:   return translated_text
Algorithm 3 Sentiment Classification
Input: Text (raw or translated)
Output: sentiment_label
1:   prompt ← """
       Classify the sentiment of the following text as:
       Positive, Negative, or Neutral.
       Respond ONLY with one label.
       Text: """ + text
2:   request_body ← {
          "contents": [{ "parts": [{ "text": prompt }] }]
     }
3:   response ← HTTP.POST(
          "gemini-1.5-flash:generateContent",
          request_body
     )
4:   sentiment_label ← extractLabel(response.text)
5:   confidence_score ← estimateConfidence(response)
6:   return (sentiment_label, confidence_score)
Algorithm 4 Analytics Aggregation
Input: List of processed posts posts[]
Output: Analytics summary object
1:   Group posts by date
2:   For each date group:
3:        count_positive ← count(sentiment == positive)
4:        count_negative ← count(sentiment == negative)
5:        count_neutral  ← count(sentiment == neutral)
6:        percentages ← computePercentage(counts)
7:        keywords ← extractTopKeywords(posts)
8:        top_posts ← selectHighConfidence(posts)
9:        Save results to analytics_cache
10:  return analytics_summary

2:   request ← buildRequest(platform, query_parameters)

4:   posts ← parseResponse(response)
5:   For each post in posts:
6:        Validate required fields
7:        Insert post into raw_posts
8:   Handle rate limits using exponential backoff
9:   return posts

6:   return report_file
Algorithm 7 Error Handling
Input: Error object error, component name
Output: None
1:   severity ← classifyError(error)
2:   Log error message, stack trace, component to system_logs
3:   if severity == transient then
4:        Retry operation with exponentialBackoff()
5:   else if severity == critical then
6:        Notify system and halt component
7:   end if
Algorithm 8: Backend User Authentication
Input: email, password
Output: access_token or AuthenticationError
1:   user ← UserRepository.findByEmail(email)
2:   if user == NULL then
3:        return AuthenticationError("User not found")
4:   end if
5:   isValid ← bcrypt.compare(password, user.hashed_password)
6:   if isValid == false then
7:        return AuthenticationError("Invalid credentials")
8:   end if
9:   payload ← { "userId": user.id, "email": user.email }
10:  access_token ← JWT.sign(payload, SECRET_KEY, expiry=24h)
11:  return access_token
Algorithm 8.1: JWTMiddleware
Input: request, response, next()
Output: Request allowed or AccessDenied
1:   token ← request.headers["authorization"]
2:   if token == NULL then
3:        return AccessDenied("Missing token")
4:   end if
5:   try:
6:        decoded ← JWT.verify(token, SECRET_KEY)
7:   catch VerificationFailed:
8:        return AccessDenied("Invalid or expired token")
9:   end try
10:  request.user ← decoded
11:  next()
Algorithm 9: CallDataSourceService
Input: endpoint, payload
Output: response_data

Conclusion and Future Work
This chapter concludes the project by summarizing the achievements and highlighting potential future directions for the PakSentiment platform.
Conclusion
The PakSentiment project successfully addressed the need for a comprehensive, multi-platform sentiment analysis system tailored to the Pakistani digital landscape. By integrating data from YouTube, Reddit, Twitter (X), and localized news portals through a high-performance scraping architecture (Go-based Colly and Python-based Scrapling), the system provides a holistic view of public opinion across diverse digital mediums.
The implementation of a hybrid backend—utilizing NestJS for core business logic and FastAPI for specialized AI processing—allowed for a scalable and maintainable environment. The utilization of Large Language Models (LLMs) via Groq and local Ollama instances ensured high-accuracy sentiment classification, capturing linguistic nuances that traditional rule-based methods often miss. Ultimately, the project demonstrates how modern web technologies and AI can be synthesized to provide actionable insights for researchers, businesses, and policymakers interested in the Pakistani socio-political and economic context.
Future Work
While the current system provides a robust foundation, several areas for future enhancement have been identified to increase its utility and precision:
Direct Urdu Language Support: Implementing dedicated LLM fine-tuning or specialized embedding models for Roman Urdu and script-based Urdu to capture nuances in local dialects and slang more accurately.
Real-Time Dashboarding: Expanding the analytical dashboard with WebSocket integration to allow for live sentiment tracking during major national events, such as elections or breaking news.
Multimodal Analysis: Incorporating AI models capable of analyzing sentiment within video frames and shared images (memes), which are significant drivers of public opinion in the local digital space.
Mobile Application Development: Developing a dedicated mobile application (via React Native or Flutter) to provide users with on-the-go access to sentiment alerts and real-time reports.
Predictive Analytics: Leveraging historical data to build predictive models that can forecast shifts in public sentiment or identify emerging flashpoints before they reach a peak.
Expanded Data Sources: Integrating additional platforms such as Facebook and Instagram, and expanding news coverage to include more regional and community-based digital newspapers.
